# v91.4 — Precise Home/Search/Community/Profile Fix

This release is intentionally limited to the requested fixes:

- Home search suggestions list public site bots by interaction count, but do not show chat counts.
- Search focus has no purple focus rectangle/ring.
- Home desktop uses recommendation rails distinct from Community and without a Picks section.
- Community on mobile uses two columns and compact cards to use lateral space.
- Clicking a bot from Community closes the Community view and opens the chat.
- Admin profile reconciliation ensures the known editorial/admin-seeded characters are linked to the admin account and included in Created bots.
- `npm run db:audit:admin-bots` identifies any known editorial bot that is missing or not owned by the configured admin.

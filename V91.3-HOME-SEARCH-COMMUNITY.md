# v91.3 — Home Search + Community Mobile + Profile Count

Precise follow-up to v90.1. Changes are limited to:
- Home search suggestions now appear on focus and use public site bots, ranked by interactions and likes.
- Home search focus no longer draws the purple focus rectangle.
- Search dropdown receives a dedicated stacking context to prevent the Home logo/other layers from overlapping it.
- Community mobile uses compact two-column cards with classified sections.
- Own profile Postgres view includes private owned bots and exposes the total owned-bot count separately from the visible list.

# Phase 71 — Mobile Refinement (final scope)

This phase is **mobile-only**. Desktop and backend behavior remain based on the v70.1 baseline.

## Included
- 360–430px mobile layout refinement.
- Compact Home hero and earlier character discovery.
- Intentional horizontal character rails.
- Denser mobile Chats rows with preview/date.
- Safe-area spacing for fixed bottom navigation.
- Compact mobile Profile cover/header.
- Mobile touch-target and text-overflow safeguards.
- Mobile-only search text/caret visibility.

## Explicitly not included
- Desktop sidebar/layout changes.
- Backend/API/data-model changes.
- Create Character changes.
- Desktop naming/layout changes.

## Validation
The mobile CSS is scoped to mobile breakpoints. The v70.1 application/page baseline is preserved to avoid desktop regressions.

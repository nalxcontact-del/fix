# V87 — Visual System

## Typography
- UI/body: Inter
- Display/headings/brand: Plus Jakarta Sans
- Buttons inherit Inter with 700 weight for clear affordance

Inter is optimized for screen/UI use; Plus Jakarta Sans is used sparingly for headings to add personality without sacrificing UI legibility.

## Visual rules
- Preserve existing PersonaChat dark/light themes.
- Use restrained elevation; not every surface becomes a card.
- Keep existing layout contracts and mobile touch targets.
- Primary controls share press/hover behavior.
- Focus states remain visible for keyboard users.
- Scrollbar styling is cosmetic only and does not change scroll containers.
- Reduced-motion behavior remains intact.

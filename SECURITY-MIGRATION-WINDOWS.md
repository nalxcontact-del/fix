# Security dependency migration — Windows\n\nThe previous migration script pinned `sharp` to `0.35.3`, while Next.js 16.3.3 resolves `sharp` to `0.35.4` in this dependency tree. That made `npm ls` report `sharp@0.35.4 invalid: "0.35.3" from node_modules/next`.\n\nThis revision removes the hard `sharp` override and instead verifies that the resolved version is on the patched `>=0.35.0` line. This avoids fighting Next.js's own dependency resolution while preserving the security requirement.\n\nAfter running the migration, validate with:\n\n```powershell\nnpm ci\nnpm run lint\nnpm run build\nnpm audit --audit-level=high\n```\n\nDo not use `npm audit fix --force`; dependency versions should remain controlled by the project lockfile.\n
